# IAMGREATER.net — Vibe Coding & Agentic Showcase

Showcase of vibe coding, autonomous AI agents, Linux power tools, and high-velocity digital craft.

## Features
- **Cyber / Dark Aesthetic**: Mesh background glows, neon cyber gradients, Fira Code monospace accents, responsive glass layout.
- **Interactive Vibe Terminal**: Type or click commands (`help`, `projects`, `manifesto`, `stack`, `spark`, `vibe`, `clear`).
- **Dynamic Projects Gallery**: Categorised portfolio filter (AI Agents, OS & Linux, Audio & Music, Web & Cloud).
- **Ideas & Manifestos**: Short essays on vibe coding, local AI sovereignty, and ethical hosting.
- **Docker Ready**: Includes `Dockerfile` and `docker-compose.yml` (mapped to port 8082).

## Local Preview
Run any static HTTP server from this folder:
```bash
python3 -m http.server 8082
```
Then visit: `http://localhost:8082`

## Hosting on ZimaOS
Copy this directory to your ZimaOS storage or use the joint docker-compose setup in `~/Projects/zimaos-websites`.
